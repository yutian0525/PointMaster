设函数 f(x) = x³ − 3x + 2，下列关于 f(x) 极值的说法，正确的是？
A
f(x) 在 x = 1 处取得极大值，在 x = −1 处取得极小值
B
f(x) 在 x = −1 处取得极大值，在 x = 1 处取得极小值
C
f(x) 在 x = 0 处取得极值
D
f(x) 没有极值
✅ 回答正确！ 用时 18 秒（预期 30 秒）
解析：f'(x) = 3x² − 3 = 3(x+1)(x−1)，令 f'(x) = 0 得 x = ±1。 f''(−1) = −6 < 0，故 x = −1 为极大值点；f''(1) = 6 > 0，故 x = 1 为极小值点。

核心概念 必读
导数与极值的关系
导数为 0 的点称为驻点，是极值点的必要不充分条件。

判断极值的方法：
① f'(x) 在 x₀ 两侧变号 → 极值点
② f''(x₀) > 0 → 极小值点
③ f''(x₀) < 0 → 极大值点

解题模板 必读
求极值的标准步骤
① 求 f'(x)
② 令 f'(x) = 0，解出所有驻点
③ 判断极值类型：二阶导数法或符号变化法
④ 代入求极值：计算 f(x₀)

⚠️ 易错点 重点
驻点 ≠ 极值点
f'(x₀) = 0 不能直接断定是极值点！

反例：f(x) = x³
f'(0) = 0，但两侧均 ≥ 0，不变号。
∴ x=0 不是极值点，而是拐点。
💬 选中文字提问
典型例题
f(x) = 2x³ − 9x² + 12x − 3 的极值
f'(x) = 6(x−1)(x−2)，令 f'=0 得 x=1, x=2
f''(1)=−6<0 → x=1 极大值 = 2
f''(2)=6>0 → x=2 极小值 = 1

什么是拐点？
拐点是函数凹凸性改变的点，即 f''(x) 变号处。

· 极值点：f' 变号
· 拐点：f'' 变号

f''(x₀)=0 也不一定是拐点。
