设函数 f(x) = x³ − 3x + 2，下列关于 f(x) 极值的说法，正确的是？
A
f(x) 在 x = 1 处取得极大值，在 x = −1 处取得极小值
B
f(x) 在 x = −1 处取得极大值，在 x = 1 处取得极小值
C
f(x) 在 x = 0 处取得极值
D
f(x) 没有极值
✅ 回答正确！ +1.0 分 用时 18 秒（预期 30 秒）
解析：f'(x) = 3x² − 3 = 3(x+1)(x−1)，令 f'(x) = 0 得 x = ±1。 f''(−1) = −6 < 0，故 x = −1 为极大值点；f''(1) = 6 > 0，故 x = 1 为极小值点。

微学习：导数 — 链式法则
由 Agent 推荐 · 重点关注：链式法则在复合函数求导中的应用
知识点详解

导数表示函数在某一点的瞬时变化率，几何意义为函数图像在该点的切线斜率。 它是微积分的核心概念之一，是研究函数性质（单调性、极值、凹凸性等）的重要工具。

对于复合函数 y = f(g(x))，求导时不能简单地对外层函数求导，而需要使用链式法则：

(f(g(x)))' = f'(g(x)) · g'(x)

也就是说：先对外层函数求导（保持内层函数不变），再乘以内层函数的导数。 这一规则可以推广到多层嵌套的复合函数：每加一层嵌套就多乘一个该层函数的导数。

常见误区：初学者容易在求导时忘记乘内层函数的导数。 例如 (sin(2x))' 的正确答案是 2cos(2x)，不是 cos(2x)。 请始终留意"是否还有内层函数没有求导"。

核心概念
导数定义
函数 f(x) 在 x₀ 处的导数定义为差商的极限。
f'(x₀) = lim[h→0] (f(x₀+h) − f(x₀)) / h
链式法则
复合函数求导：外层导数乘以内层导数。
(f∘g)'(x) = f'(g(x)) · g'(x)
极值判定
驻点处二阶导数符号决定极值类型。
f'(x₀)=0 且 f''(x₀)<0 → 极大值
追问记录
Q: 为什么链式法则要乘内层导数？直观上怎么理解？
A: 可以从"变化率传递"的角度理解。如果 g(x) 变化 1 个单位会让 g 增加 g'(x) 个单位，而 f 对 g 的变化率是 f'(g(x))，那么 x 变化 1 个单位最终让 f 变化 f'(g(x)) · g'(x) 个单位。
