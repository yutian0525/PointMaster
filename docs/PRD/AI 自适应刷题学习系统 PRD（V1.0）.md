# 一、产品概述

## 1.1 产品简介

PointMaster 慧刷题是一款基于 **AI 动态知识诊断 + 微学习 + 强化训练** 的智能学习系统。

系统通过：

- AI 自动解析题库，提取知识点并构建知识图谱
- 动态评估用户对各知识点的掌握情况
- 智能决定何时继续刷题、何时进入微学习
- 针对性强化训练，验证掌握成果

帮助用户用最少时间，真正掌握整个题库知识点。

---

## 1.2 产品定位

PointMaster 不是传统刷题软件，也不是单纯的 AI 讲题工具，而是：

**AI 驱动的个性化知识掌握系统**

| 传统刷题 | PointMaster |
|----------|-------------|
| 盲目刷题 → 重复浪费 | 动态诊断 → 发现漏洞 → 快速学习 → 强化验证 → 真正掌握 |

# 二、目标用户

## 2.1 核心用户

| 用户类型 | 代表场景 |
|----------|----------|
| 考试备考 | 考研、考公、法考、CPA、医学考试、教资 |
| 学生群体 | 高中、大学、编程学习 |

## 2.2 用户特点

- 已拥有题库（自购或机构提供）
- 时间有限，不想题海战术
- 想快速找到薄弱点并针对性提升

# 三、核心产品理念

```
动态诊断 → 发现漏洞 → 快速学习 → 强化验证 → 真正掌握
```

核心目标：**少刷题，但更快掌握知识**

1. **AI 精准诊断**：快速定位知识漏洞
2. **动态学习策略**：系统动态判断用户当前更需要刷题还是学习
3. **微学习机制**：2~5 分钟快速掌握薄弱点
4. **个性化强化训练**：只做当前最值得做的题

## 模块 1：题库导入系统

### 功能目标

支持用户快速导入题库，AI 自动完成知识点提取与知识图谱构建。

### 导入流程

```
上传文件
  ↓
系统解析（格式校验 + 题目提取）
  ↓
AI 知识点提取（每题标注知识点、难度、题型）
  ↓
AI 构建知识图谱（知识点依赖关系、学习先后顺序）
  ↓
存入结构化题库
```

### MVP 支持格式

- Excel（推荐）
- JSON
- TXT

### 后续支持

- PDF、Word、OCR 扫描

### Excel 模板格式

| 题目 | A | B | C | D | 答案 | 解析 |
|------|---|---|---|---|------|------|

### AI 知识点提取输出示例

输入题目：`求函数 f(x)=x³-3x 的极值`

```json
{
  "knowledge_points": ["导数", "极值", "函数单调性"],
  "difficulty": 0.68,
  "question_type": "计算题",
  "prerequisite_points": ["导数定义", "求导法则"]
}
```

### 知识图谱结构

AI 在提取知识点后，自动分析知识点之间的依赖与关联关系，构建有向知识图谱，作为学习路径规划的基础。

```
高数
 ├── 极限
 │    └── 导数定义（依赖极限）
 │         ├── 求导法则
 │         │    ├── 极值（依赖求导法则）
 │         │    └── 函数单调性
 └── 积分
      └── 定积分计算
```

## 模块 2：练习模式系统

用户选择一个题库后，创建练习，支持两种模式：

---

### 2.1 快速刷题模式

**适用场景**：系统性学习，按知识点先后顺序逐一掌握。

**核心逻辑**：

```
按知识图谱顺序，取第一个知识点
        ↓
    自适应刷题（当前知识点）
        ↓
   实时更新掌握度
        ↓
  ┌─── 掌握度 < 阈值（默认 0.7）───┐
  │                                 ↓
  │                         进入微学习（当前知识点）
  │                                 ↓
  │                         学习完成，继续自适应刷题
  │                                 │
  └─────────────────────────────────┘
        ↓
  掌握度 ≥ 阈值 或 用户手动点击「下一知识点」
        ↓
    进入下一知识点
        ↓
  所有知识点完成 → 生成完整掌握报告
```

**关键设计**：
- 知识点顺序依据知识图谱的依赖关系确定（先学前置知识点）
- 用户可随时手动跳过当前知识点
- 进入微学习的条件：`mastery < 0.7 且 confidence > 0.6`（已有足够置信度判断用户确实不会）

---

### 2.2 查缺补漏模式

**适用场景**：已有一定基础，针对薄弱环节集中突破。

**核心逻辑**：

```
开始自适应刷题（覆盖所有知识点）
        ↓
系统动态分析各知识点掌握情况
（每做 10~15 题 或 达到置信度阈值，触发一次评估）
        ↓
  ┌─── 选出掌握度最低的 1~3 个知识点 ───┐
  │                                      ↓
  │                             进入微学习（依次学习）
  │                                      ↓
  │                             学习完成，继续自适应刷题
  │                                      │
  └──────────────────────────────────────┘
        ↓
  掌握度均 ≥ 阈值 或 用户手动点击「退出」
        ↓
    生成知识点掌握报告 + AI 学习建议
```

**关键设计**：
- 刷题阶段不限定知识点，混合出题，全面探测用户水平
- 进入微学习的知识点数量：系统默认选 1~3 个，用户可手动调整
- 退出时必须生成报告，不可跳过

## 模块 3：自适应刷题算法

### 3.1 用户能力模型

每个用户在每个知识点上维护两个核心参数：

| 参数 | 取值范围 | 含义 |
|------|----------|------|
| `mastery`（掌握度） | 0~1 | 用户对该知识点的掌握程度 |
| `confidence`（置信度） | 0~1 | 系统对当前掌握度评估的可信程度 |

### 3.2 动态出题策略

```
初始：每个知识点抽 1 题，快速建立用户画像
        ↓
根据答题结果动态调整下一题：

  答对 → 提高难度，继续测试
  连续答对 3 题 → 置信度提升，减少该知识点测试量
  答错 → 降低难度，更换题型，继续定位问题
  连续答错 2 题 → 触发微学习评估
```

### 3.3 掌握度更新算法

综合考虑**答题正确性**和**答题时间**，动态调整掌握度：

**答对时：**
```
time_factor = clamp(1 - (answer_time / expected_time), 0, 1)
mastery += difficulty × 0.1 × (1 + time_factor × 0.5)
confidence += 0.15
```

**答错时：**
```
mastery -= difficulty × 0.12
confidence += 0.10
```

**参数说明：**
- `answer_time`：用户实际答题时间（秒）
- `expected_time`：题目预期作答时间（由难度 × 基准时长计算，例：难度 0.5 对应 30 秒）
- `time_factor`：时间系数，答题越快加分越多，超时不惩罚
- `difficulty`：题目难度（0~1）

**掌握度边界：** `mastery` 限制在 `[0, 1]` 范围内

### 3.4 停止测试条件（满足任一即停止当前知识点测试）

| 条件 | 说明 |
|------|------|
| `confidence > 0.8` | 系统已足够了解用户水平 |
| 连续答对 3 题 | 稳定正确，认定掌握 |
| 连续答错 2 题 | 稳定错误，触发微学习 |

### 3.5 微学习触发条件

```
confidence > 0.6 AND mastery < 0.7
```

> 两个条件缺一不可：置信度高说明已充分评估（不是运气），掌握度低说明确实有薄弱点。

## 模块 4：微学习系统

### 4.1 功能目标

当系统判断用户对某知识点掌握不足时，进入 2~5 分钟的快速学习阶段，通过知识卡片 + 交互提问的方式帮助用户快速补足知识漏洞。

### 4.2 微学习内容结构（AI 生成）

每个知识点的微学习内容由 AI 自动生成，包含以下卡片：

| 卡片类型 | 内容 |
|----------|------|
| **核心概念卡** | 知识点的核心定义与关键结论 |
| **识别信号卡** | 什么情况下应想到这个知识点（题目关键词映射） |
| **解题模板卡** | 步骤化解题框架 |
| **易错点卡** | 高频错误与反例（重点标注） |
| **例题卡** | 1~2 道典型例题，含详细解析 |

### 4.3 知识卡片界面设计

界面以**卡片流**形式展示，每张卡片独立呈现一个知识块：

```
┌─────────────────────────────────────────┐
│  📌 核心概念：导数与极值                  │
│                                         │
│  导数为 0 的点叫做 **驻点**，            │
│  驻点不一定是极值点。                    │
│  需用二阶导数或符号变化判断。             │
│                                         │
│  [划词提问：选中文字可提问]              │
└─────────────────────────────────────────┘
         │ 连线（知识关联）
         ↓
┌─────────────────────────────────────────┐
│  ⚠️ 易错点                              │
│                                         │
│  f'(x)=0 ≠ 极值点                       │
│  反例：f(x)=x³，f'(0)=0 但 x=0 不是极值  │
└─────────────────────────────────────────┘
```

**卡片间关联**：相关卡片之间用连线标注关系（如"依赖"、"补充"、"反例"）。

### 4.4 划词提问功能

用户可在卡片内**选中任意关键词或语句**，触发 AI 提问入口：

```
操作：选中「驻点」
        ↓
弹出提问框：「驻点是什么？」（系统预填，用户可修改）
        ↓
AI 生成答复，形成一张新的「延伸知识卡片」
        ↓
新卡片以连线与原卡片关联，插入卡片流
```

**新卡片结构**：
- 标题：用户提问的关键词
- 内容：AI 针对该词/句的简洁解释
- 来源标注：「由『核心概念卡』延伸」
- 连线类型：「延伸说明」

### 4.5 微学习完成条件

- 用户阅读完所有基础卡片（核心概念、识别信号、解题模板、易错点）
- 完成例题卡的练习（可选：直接查看答案）
- 点击「完成学习，继续刷题」

---

## 模块 5：强化训练系统

### 功能目标

微学习完成后，用少量题目验证用户是否真正掌握。

### 强化逻辑

系统推荐：
1. 当前薄弱知识点的中等难度题
2. 覆盖多个相关知识点的高价值综合题
3. 历史做错的同类题（变式练习）

**强化目标**：不是继续刷很多题，而是用 3~5 道题确认已经真正掌握。

---

## 模块 6：掌握度分析与报告

### 功能目标

在查缺补漏模式退出时（以及阶段性学习完成时）生成知识掌握报告。

### 报告内容

**1. 知识点掌握度总览**

```
导数        ████████░░  82%   ✅ 良好
积分        ███░░░░░░░  34%   ⚠️ 薄弱
极限        ██████░░░░  61%   📌 待提升
```

**2. 学习行为数据**

| 指标 | 数值 |
|------|------|
| 本次刷题数 | 42 题 |
| 进入微学习次数 | 3 次 |
| 平均答题时间 | 28 秒/题 |
| 知识点覆盖数 | 8 / 12 |

**3. AI 学习建议**

AI 根据掌握度分布和答题行为，生成个性化建议，例如：

> 建议优先强化「积分」知识点，你在积分计算中频繁出现符号错误，建议重点复习「换元积分法」的步骤模板。「极限」掌握度接近良好线，再做 5~8 道练习即可巩固。

---

## 模块 7：推荐系统

系统动态判断用户当前最应该做什么：

| 推荐类型 | 触发条件 |
|----------|----------|
| 推荐下一题 | 当前知识点置信度不足，继续评估 |
| 推荐进入微学习 | `confidence > 0.6 AND mastery < 0.7` |
| 推荐强化训练 | 微学习完成后 |
| 推荐下一知识点 | 当前知识点掌握度达标 |
| 推荐退出并查看报告 | 所有目标知识点掌握度达标 |

# 九、MVP 阶段范围

## MVP 包含

- 题库导入（Excel / JSON / TXT）
- AI 知识点提取与树状分类
- 快速刷题模式（完整闭环）

- AI 视频讲课

- OCR 扫描
- 多端同步
- 知识图谱可视化界面（后台建图，前端暂不展示图谱）

# 十一、核心产品指标

| 指标 | 目标 |
|------|------|
| 用户完成「诊断→学习→强化」完整闭环率 | > 60% |
| 微学习后下一轮刷题正确率提升 | > 20% |
| 用户感知「系统真的懂我的问题」满意度 | > 4.0/5.0 |
| 相比传统刷题，用户感知题量减少 | > 30% |

# 十二、PointMaster 的本质

PointMaster 本质不是 AI 题库，而是：

**AI 驱动的个性化知识掌握系统**

核心能力：系统在每一步动态判断「用户下一步最需要什么」，并精准执行。
