# 设计稿 V2.0 更新 — 设计规格

## 概述

基于 PRD V2.0 的架构变更，更新 `docs/design/index.html` 前端设计原型。核心变化：Agent 驱动统一练习流程、做题+微学习同页、Agent 决策弹窗、练习回顾时间线。

## 页面结构变更

| 现有页面 | V2.0 变化 |
|----------|-----------|
| 首页 | **更新** — 去掉模式标签，记录显示 block 数，点击进入回顾页 |
| 题库管理 | **更新** — 每个 bank card 加「开始新练习」按钮 |
| 题库详情 | **更新** — 加「开始新练习」按钮 |
| 模式选择 | **删除** |
| 做题页 | **重构** → 统一练习页（做题+微学习同区域切换） |
| 微学习(画布) | **删除独立页** — 合入统一练习页，改为线性阅读 |
| 报告页 | **保留** |
| Agent 决策弹窗 | **新增** |
| 练习详情/回顾页 | **新增** |

## 侧边栏更新

- 删除「练习模式」导航项
- 「自适应刷题」改为「练习」
- 删除独立「微学习」导航项
- 新增「练习历史」放在「进行中」section（可选，当前从首页列表进入即可）

## 统一练习页（核心重构）

### 整体布局
```
┌─ 顶栏 ────────────────────────────────────────────────┐
│  题库名  ·  Block N  ·  第 M/K 题   [结束练习]        │
└───────────────────────────────────────────────────────┘
┌─ 主内容区 (70%) ─────────┐  ┌─ 侧栏 (30%) ──────────┐
│                           │  │                        │
│   做题时：题目+选项       │  │  掌握度列表            │
│   微学习时：学习内容      │  │  本 Block 统计         │
│   （同区域平滑替换）      │  │  session 进度         │
│                           │  │                        │
└───────────────────────────┘  └────────────────────────┘
```

### 做题态

**顶栏**：
- 左：题库名 + 当前知识点
- 中：Block 进度（「Block 2 · 第 3/5 题」）
- 右：「结束练习」按钮

**主区域**：
- 题目卡片：题号 + 难度指示 + 题目内容
- 选项/输入区（根据题型切换）
- 底部：「跳过」「确认答案 →」
- 答题后：即时反馈区（对/错 + 解析 + 得分）
- Block 最后一题答完 → 自动弹出 Agent 决策弹窗

**侧栏**：
- 知识点掌握度列表（实时更新）
- 本 Block 统计：正确/错误数
- Session 概览：已完成 N 个 Block、N 题

### 微学习态

主区域内容平滑替换为：

```
┌─────────────────────────────────────────────┐
│  📖 微学习：导数 — 链式法则                   │
│                                             │
│  ── 知识点详解 ──                            │
│                                             │
│  [Markdown 渲染的详细解读内容]               │
│  用户可选中任意文字提问                      │
│                                             │
│  ── 核心概念 ──                              │
│                                             │
│  ┌─ 概念卡片 1 ─────────────────┐            │
│  │ 标题 + 内容 + 公式           │            │
│  └───────────────────────────────┘            │
│  ┌─ 概念卡片 2 ─────────────────┐            │
│  │ 标题 + 内容 + 公式           │            │
│  └───────────────────────────────┘            │
│                                             │
│  ── 追问记录 ──（如有）                      │
│  Q: 用户问题                                │
│  A: AI 回答                                 │
│                                             │
│  [学完了，继续练习 →]                        │
└─────────────────────────────────────────────┘
```

**划词提问**：
- 选中文字 → 弹出小气泡「💬 对「xxx」提问」
- 点击后在内容下方追加问答对
- 追问区域随内容增长，可滚动

**侧栏**：保持不变（掌握度 + 统计）

### 态切换动画
- 做题 → 微学习：主区域内容淡出/淡入（fadeOut→fadeIn，约 300ms）
- 微学习 → 做题：同上

## Agent 决策弹窗

### 触发
Block 最后一题答完且反馈显示后，自动弹出

### 布局
```
┌───────────── 模态弹窗 (520px 宽) ─────────────┐
│                                               │
│  🤖 Agent 分析中...                            │
│  ─────────────────────────                    │
│                                               │
│  [流式打字效果显示分析内容]                     │
│  "你在「导数」知识点连续两个 block 正确率       │
│   低于 50%，建议先学习巩固再继续..."            │
│                                               │
│  ── 建议 ──                                   │
│  📖 进入「导数」微学习                         │
│  重点关注：链式法则应用                        │
│                                               │
│  ── 下一步预览 ──                              │
│  微学习后将用 5 道简单题验证                    │
│                                               │
│  ┌────────────────────────────────────────┐   │
│  │ [接受建议]  [继续刷题]  [选择知识点]    │   │
│  │                          [结束练习]     │   │
│  └────────────────────────────────────────┘   │
└───────────────────────────────────────────────┘
```

### 交互细节
- 背景遮罩（半透明黑）
- 弹窗居中，有阴影
- 分析文本逐字/逐句流式出现（打字机效果）
- 流式完成前按钮 disabled
- 流式完成后按钮 enabled，高亮「接受建议」为主按钮
- 点击「选择知识点」展开下拉列表供用户手动选

### 加载态
```
🤖 Agent 分析中...
[●●●] 正在分析本次 block 表现...
```

## 样式规范

延续现有设计体系：
- 主题色：`#9fb997` / `#c8d4c0`
- 背景色：`#f4f2f0`
- 字体：Fraunces（标题）+ Plus Jakarta Sans（正文）
- 圆角：sm(8px) / md(14px) / lg(22px) / xl(28px)
- 阴影：sm / md / lg 三级

### 新增 Agent 相关样式
- Agent 弹窗背景：`rgba(30,40,34,.32)` + `backdrop-filter: blur(3px)`
- 流式文本：逐字出现，用 CSS animation 或 JS interval
- Agent 图标/标记：使用 🤖 或自定义 AI 图标
- 建议卡片：绿色边框高亮（接受建议时）

### 时间线样式
- 垂直连接线：`2px solid var(--border)`
- 步骤图标：圆形背景
  - Block：📝 绿色系
  - Agent：🤖 紫/蓝色系
  - 微学习：📖 黄色系
  - 报告：📊 灰色系
- 展开/收起：chevron 箭头 + 平滑展开动画

## 实现要点

1. **删除**：`page-mode` 页面及相关 CSS/JS
2. **删除**：`page-micro` 独立画布页面及所有 canvas/drag 相关代码
3. **重构**：`page-quiz` 为统一练习页（做题态 + 微学习态切换）
4. **新增**：Agent 决策弹窗组件（模态 + 流式文本动画）
5. **新增**：`page-session-detail` 练习详情回顾页
6. **更新**：`page-home` 首页内容适配
7. **更新**：`page-banks` 和 `page-bankdetail` 加「开始新练习」按钮
8. **更新**：侧边栏导航项

## 不变的部分

- 整体布局框架（sidebar + main）
- 题库管理页核心功能
- 题库详情页（知识图谱可视化、节点弹窗）
- 报告页
- 设计 token（颜色、字体、圆角、阴影）
- 响应式断点和滚动条样式
