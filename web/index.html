零延迟反馈

选题、判分、掌握度更新全在本地算，提交到反馈 < 200ms，做题不卡顿。

时间因子加权

答得又快又对，掌握度涨得更多；犹豫越久，加成越少——考场直觉一并纳入。

AI 只在关键路径外

LLM 负责建图谱、排知识点顺序、单题答疑；刷题主循环不依赖它，稳定又流畅。

mastery.ts · 掌握度更新
// 每答一题实时更新（客观题 score 为 0 / 1）
if (score >= 1) {
  // 答对：越快越对，涨得越多
  const timeFactor = clamp(1 - answerTime / expectedTime, 0, 1)
  mastery    += difficulty * 0.1 * (1 + timeFactor * 0.5)
  confidence += 0.15
} else {
  // 答错：按难度扣分，置信度仍上升
  mastery    -= difficulty * 0.12
  confidence += 0.10
}
mastery = clamp(mastery, 0, 1)
当 confidence > 0.6 且 mastery < 0.7，系统判定「懂一点但没吃透」，触发微学习。
